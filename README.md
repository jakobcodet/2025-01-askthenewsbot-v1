**The “Ask the news” bot is a prototype that was created as part of a seminar at the University of Leipzig.**

The *main* script controls a Telegram bot via API and forwards user questions to the *PerplexityStuff* script, which answers them using the Perplexity API.

You need your own Telegram bot to run it (created free of charge by the Telegram user @BotFather) and a key for the Perplexity API (for a fee).
